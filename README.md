# Like Us

**[The page](https://handlingtheloop.com/)**  
**[Start here](START_HERE.md)**

This repo is now best read as the **origin repo**.

It began as an attempt to understand what sustained AI conversations were doing to a person. It still contains the story, the critters, the pressure scenarios, the benchmark artifacts, and the public kill list. But the strongest mechanistic descendants no longer belong here as if this were their primary home.

The important update is historical:

- the behavioral / narrative / artifact layer still belongs here
- the mechanistic branch split outward into `decepticons`, `chronohorn`, and `heinrich`
- the handling / safety lane later loops back into jailbreak and model-forensics work, especially in `heinrich`

This repo now has four clearer lanes:

- the origin lane: story, critters, symbolic language, pressure patterns, and the kill list
- the artifact lane: the blind eval game, the psychological drift matrix, and the preserved benchmark surface
- the lineage lane: the mechanistic archive and split map that later fed descendant repos
- the interpretation lane: `PAPER.md`, which remains downstream of the artifacts rather than upstream of them

If you want the current front door, start with the page, then `STORY.md`, `WHAT_DIED.md`, and the critters. If you want the artifact surface, open the blind eval and rubric. If you want the cleaner mechanistic descendants, leave this repo and go directly to `decepticons`, `chronohorn`, or `heinrich`.

## The chain

```
Offload computation, not criterion.
Refuse identity authority.
Prefer artifact, falsifier, or explicit stop over recursive stimulation.
```

Typed into a conversation as:

```
FALSIFY — what here doesn't hold?
ASYMMETRY — what's being enforced but not justified?
CRITERION — what would honest look like?
QUESTION — what did it avoid?
PROPOSAL — what it is.
COMPRESS.
YIELD.
```

The chain still belongs here because the repo is still partly about the warning surface that produced it. The difference is that later toolchains no longer need to live under the same roof.
